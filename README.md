## 🔧 Setup & Installation

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No build process required – runs directly in the browser

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/dns-18/portfolio.git
   cd portfolio
   ```

2. **Open in browser**
   ```bash
   # Option 1: Double-click index.html
   # Option 2: Use a local server
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

3. **Navigate the site**
   - **Home** – Hero section with main introduction
   - **Projects** – Featured work highlights (click "VIEW ALL WORK" for details)
   - **About** – Bio and professional information
   - **Contact** – Social links and email

## 📖 Usage

The portfolio is fully functional without a build step. All animations and interactions work in vanilla JavaScript:

- **Smooth Scrolling:** Powered by Locomotive Scroll – navigate sections smoothly
- **Mouse Tracking:** Custom circle follows cursor with skew animation
- **Project Hover:** Images appear and rotate on project hover
- **Mobile Menu:** Responsive navigation toggle on smaller screens
